## Target database contract (`server/src/db/types.ts`)

Async-only. No `prepare()`. No fake sync.

```ts
interface Db {
  query<T>(sql, params?): Promise<QueryResult<T>>;   // { rows, rowCount }
  get<T>(sql, params?):   Promise<T | undefined>;
  all<T>(sql, params?):   Promise<T[]>;
  run(sql, params?):      Promise<RunResult>;          // { changes, lastInsertRowid? }
  exec(sql):              Promise<void>;
  transaction<T>(fn: (tx: Db) => Promise<T>): Promise<T>;
  close():                Promise<void>;
}
```

SQL is written in upstream's SQLite-flavoured style (positional `?`); `db/pg.ts`
translates `?` → `$1..$n`, skipping string literals / quoted identifiers /
comments / dollar-quoted bodies.

### Sync → async transform table

| Upstream (SQLite, sync) | New (PostgreSQL, async) |
|---|---|
| `getDb().prepare(SQL).get(a,b)` | `await getDb().get(SQL, [a,b])` |
| `getDb().prepare(SQL).all(a,b)` | `await getDb().all(SQL, [a,b])` |
| `getDb().prepare(SQL).run(a,b)` | `await getDb().run(SQL, [a,b])` |
| `getDb().prepare(SQL).get()` | `await getDb().get(SQL)` |
| `getDb().exec(SQL)` | `await getDb().exec(SQL)` |
| `getDb().transaction(fn)` (sync fn) | `await getDb().transaction(async (tx) => …)` |
| `tx.prepare(SQL).run(x)` | `await tx.run(SQL, [x])` |

Rules:
1. Any function reaching the DB becomes `async`; its callers `await` it.
2. Express 5 forwards rejected promises to the error handler ⇒ async handlers are fine.
3. Never `await` inside `map`/`forEach` — use `for…of` or `Promise.all`.
4. Preserve ordering: sequential DB work stays sequential.

### SQLite → PostgreSQL dialect table

| SQLite | PostgreSQL |
|---|---|
| `PRAGMA table_info(t)` | `SELECT column_name FROM information_schema.columns WHERE table_name = $1` |
| `INSERT OR IGNORE` | `INSERT … ON CONFLICT DO NOTHING` |
| `INSERT OR REPLACE` | `INSERT … ON CONFLICT (…) DO UPDATE SET …` |
| `AUTOINCREMENT` | `BIGINT GENERATED BY DEFAULT AS IDENTITY` |
| `datetime('now')` | `now() at time zone 'utc'` |
| `strftime('%Y-%m-%d', c)` | `to_char(c, 'YYYY-MM-DD')` |
| `julianday(x)` | epoch arithmetic (`EXTRACT(EPOCH FROM …)`) |
| `sqlite_master` | `information_schema.tables` / `pg_catalog` |
| `group_concat(x)` | `string_agg(x, ',')` |
| `json_group_array(x)` | `json_agg(x)` |
| `PRAGMA foreign_keys` | `CASCADE` on drop |
| booleans | stay `INTEGER 0/1` (deliberate: preserves upstream read semantics) |
